# C3-M07 Course Outline: CRM Hygiene: Notes, Tags, Tasks

## 1. Metadata
- **Course:** C3 Clienteling & CRM: Building a Client Book That Compounds
- **Module:** 7
- **Title:** CRM Hygiene: Notes, Tags, Tasks
- **Track:** Foundations
- **Target Personas:** P1 (New Associate), P2 (Maison Client Advisor), P3 (Cruise/Travel Specialist)
- **Estimated Study Time:** 45–60 minutes
- **Core KPIs:** CRM Profile Completeness Score, Overdue Task % (Target: 0%), Data Integrity Audit Pass Rate

## 2. Learning Objectives
1. Distinguish between high-value actionable CRM intelligence and dead administrative data.
2. Implement a standardized tagging taxonomy across metal preferences, gemstone affinities, and milestone horizons.
3. Write objective, legally compliant client profile notes that pass privacy audits (GDPR/CCPA).
4. Maintain zero-overdue task pipelines through disciplined daily workflow habits.
5. Protect high-net-worth client data against social engineering and confidentiality breaches.

## 3. Structural Breakdown
- **Section 1:** The Garbage-In, Garbage-Out Trap.
- **Section 2:** Standardized Jewelry CRM Tagging Taxonomy.
- **Section 3:** Objective Note-Taking vs. Inappropriate Subjective Clutter.
- **Section 4:** Task Pipeline Discipline & The Zero-Overdue Rule.
- **Section 5:** Client Data Privacy, Discretion, and Anti-Fraud Protocols.
- **Section 6:** Actionable Floor Drills & Weekly Practice Protocol.
