# C3-M07 Morning Huddle Card: CRM Hygiene: Notes, Tags, Tasks

## Core Principle
"Your CRM is not a personal diary. It is a shared institutional vault. Enter data that is objective, actionable, and that you would be proud to show the client if they stood beside you."

## Key Focus Points (5-Minute Team Sync)
1. **The 'Front Page Test':** Never write an opinion about a client's personality, wealth, or marriage. Write only observable facts, direct quotes, and exact measurements.
2. **Standardized Tags Only:** Always tag metal preferences (`#pref-platinum`), milestones (`#anniv-oct`), and aesthetic styles so anyone on the team can curate for them.
3. **Zero Overdue Tasks:** An overdue task is a broken promise to a client. Reschedule or complete every open task before ending your shift today!

## Daily Floor Challenge
Review five client profiles in your CRM. Clean up informal notes, add missing standardized tags, and verify all task due dates!
