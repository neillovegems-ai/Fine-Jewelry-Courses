# Daily Huddle Card: Course C4: Module 7
## Cycle Counts, Case Counts and Shrink

### ⏱️ 5-Minute Morning Briefing for the Sales Floor

**Core Principle:** *If you don't count it daily, you don't own it. Daily counts find errors in 12 hours, before trails grow cold.*

---

### 1. The Daily Morning/Evening Case Count (The 60-Second Drill)
- **Morning Open:** As each tray is placed into the showcase from the safe, conduct an instant visual count of the slots.
  - If a 12-ring tray holds 11 rings, stop immediately. Verify if slot #12 is on a valid Repair Envelope or Memo Out slip.
- **Evening Close:** Before carrying trays to the vault, verify the piece count against the morning log. If one piece is missing, **nobody leaves the floor** until the immediate 5-point sweep is complete.

---

### 2. The 5-Point Discrepancy Trace
If an item is missing from a tray, follow this exact sequence:
1. **POS Sales:** Check the day's sales register. Was it sold today and left off the manifest?
2. **Shop/Repair:** Check the repair intake bin. Was it taken in for resizing?
3. **Memo:** Check the vendor consignment binder. Was it returned or sent on memo?
4. **Physical Case Sweep:** Pull out the tray and inspect the velvet lining, case floor, and bottom drawer.
5. **CCTV Audit:** Log the exact case number and notify management to pull time-stamped camera footage.

---

### 3. The Blind Count Rule
- During weekly cycle counts, never look at what the computer system says you *should* have.
- Count the physical goods first, write down the number, and then compare. A blind count is the only count that catches switches and internal shrinkage.
