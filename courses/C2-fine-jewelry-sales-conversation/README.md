# C2 The Fine Jewelry Sales Conversation

**Track:** Foundations
**Personas:** P1, P2, P3
**10 articles, 8-10 learner hours**
**Research anchor:** Reference R2, R12, Section 2 (Career-and-Skills-Reference.md); supplementary Career Guide soft-skills section

## Terminal outcomes

The learner can:
- Open a conversation without "Can I help you?"
- Run a discovery sequence that surfaces occasion, recipient, budget range and style
- Present using feature/benefit/emotion
- Handle the eight most common objections (price, "just looking," "I'll think about it," online comparison, lab-grown, financing hesitation, partner approval, competitor quote)
- Ask for the sale three different ways
- Add on ethically

**Assessment:** Recorded or observed role-play scored against a rubric; objection-response flash cards.
**KPI link:** conversion rate, average ticket, units per transaction (UPT).
